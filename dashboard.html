    Goals & settings

    Goals (active hours)

    WHO and ILO link regular weeks of 55 hours or more to higher stroke and heart-disease risk. Tracked active time is lower than time at the desk, so set limits well below that line.

    Work window

    Activity outside this window, on other days, or after you close the day counts as after hours. Activity before the day start counts toward the previous day.

    Alerts

    On work days, working between this time and your work start doesn't trigger after-hours alerts; it still counts as after hours. Clear it to always alert.

    The end-of-day prompt always uses a system dialog, since it asks you to type tomorrow's to-dos, unless important alerts are set to Notification.
